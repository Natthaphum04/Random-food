# 🍱 Random Food 

เว็บสุ่มเมนูอาหาร สำหรับคนที่เลือกไม่ถูกว่าจะกินอะไรดีวันนี้!

## 🛠 ฟีเจอร์
- เพิ่มรายการอาหารที่คุณอยากเลือก
- สุ่มเลือกเมนูอัตโนมัติ
- ใช้งานง่ายและรวดเร็วผ่านเบราว์เซอร์

## 🚀 วิธีใช้งาน
1. พิมพ์ชื่ออาหารที่คุณอยากเลือกลงไป
2. กดปุ่ม "สุ่ม"
3. ระบบจะแสดงผลลัพธ์ให้คุณเลือกได้ทันที!
